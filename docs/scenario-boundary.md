# Scenario Boundary (场景边界声明)

## 1. 场景锚点
本周（Week5）的核心场景是：**单任务多步 Agent 的工程治理**。
重点在于让 Agent 能够安全、稳定地注册工具、校验参数、执行工具、处理错误并继续推理。单轮复杂任务拆解与工具调用治理是本项目的绝对核心。

## 2. 评估边界（本周坚决不做什么）
- **不涵盖多 Agent 协作博弈**：当前阶段不涉及多智能体通信协议与复杂博弈。
- **不涵盖长短期记忆深度演进**：不把多轮对话状态管理塞入核心链路。单次任务的状态记录在 `agent/state.py` 即可，不引入复杂的 Session、Redis。
- **不涵盖检索质量评估（RAGAS）**：评估基线为“裸 LLM” vs “带有 Policy 管控的 Agent”，重点看**工具调用成功率**与**参数拦截率**，而非 RAG 检索准确率。
- **不涵盖高级检索算法**：不把 BM25、RRF、条件 Reranker 塞入核心链路。RAG 在本周仅作为 `rag_tool.py` 的薄契约存在。

## 3. 依赖硬边界
为保证本周环境的轻量与纯粹，`requirements.txt` 绝不包含以下重型依赖：
- `chromadb` (除非 adapter 确实使用且说明原因)
- `rank_bm25` 
- `ragas`
