# Day 2 预算对比与安全边界实验记录

## 一、 实验运行方式
- **脚本位置**：`experiments/run_budget_compare.py`
- **运行命令**：`python -m experiments.run_budget_compare`（需在项目根目录运行，或脚本内注入 `sys.path`）
- **跳过退避等待**：实验脚本通过 `loop_mod.time.sleep = lambda _: None` 避免真实等待 1s、2s 的指数退避。

## 二、 无预算 vs 有预算行为对比

**构造条件**：假模型每次提议相同的工具，但参数每次微变，且工具永远成功，模拟“永不完成”的无限流转。

| 指标 | 场景 A：无预算约束 | 场景 B：有预算约束 |
| :--- | :--- | :--- |
| **配置** | MAX_STEPS=1000, 总预算=10^9 | MAX_STEPS=8, 总预算=4 |
| **步数** | 1000 | 8 |
| **超时次数** | 0 | 0 |
| **重试次数** | 0 | 0 |
| **是否被截断** | 是（达到最大步数） | 是（达到最大步数） |
| **是否卡死** | 否 | 否 |

**结论**：最大步数 `MAX_STEPS` 是确定性的截断器，防止模型陷入无意义的空转。

## 三、 读重试受总预算约束实验

**构造条件**：读工具永远超时，模型持续请求。

| 场景 | 超时次数 | 允许重试次数 | 停止原因 | 剩余预算 |
| :--- | :--- | :--- | :--- | :--- |
| **budget=1** | 2 | 1 | 总预算不足，禁止重试 | 0 |
| **budget=10** | 3 | 2 | 读操作重试次数已达上限 | 8 |

**结论**：重试同时受 `READ_RETRY_MAX=2`（次数上限）和总预算约束。不存在“每个工具重试五次、每次等十秒”导致预算击穿的情况。

## 四、 “重试反而有害”场景记录

- **场景**：写操作超时（`write_tool` 执行超过阈值）。
- **实验数据**：`timeout_count=1`，`retry_count=0`，`budget_left=10`，停止原因“写操作超时禁止直接重试”。
- **危害**：超时只代表主流程没收到响应，不代表下游没执行。直接重试可能造成重复下单、重复扣款等副作用。
- **正确策略**：写操作超时禁止直接重试。失效条件：只有当写操作有幂等键且能查询真实状态时，才允许受控重放。

## 五、 真实超时打断（变式练习）

- **教学版缺陷**：“执行后检查耗时”无法打断真正卡死的工具。如果一个工具底层卡住 10 秒，主流程依然会被阻塞。
- **真实改造**：在 `agent/loop.py` 的 `execute_with_timeout` 中使用 `ThreadPoolExecutor`，配合 `future.result(timeout=...)` 和 `executor.shutdown(wait=False)` 实现真正的超时抛出。
- **写操作安全边界**：由于 Python 线程无法被强制杀死，超时后后台线程可能仍在执行。因此，线程超时只解决“主流程不被卡住”，不解决“副作用已发生”。写操作超时后依然需要靠幂等键和状态查询兜底。

## 六、 决策记录

1. **超时阈值怎么定？默认 10s 的依据是什么？**
   - **依据**：覆盖常见读操作 P95 延迟并留余量。
   - **失效条件**：下游 P95 延迟 > 8s 时，该阈值会频繁误杀，应按 `P95 × 1.5` 动态调整。

2. **为什么读操作可指数退避重试、写操作超时不能直接重试？**
   - **依据**：读操作通常无副作用，写操作可能已执行但响应丢失。
   - **失效条件**：写操作有幂等键且可查真实状态时，才允许受控重放。

3. **最大步数和 Run Deadline 为什么必须由确定性 policy 控制，不交给模型？**
   - **依据**：模型不会可靠记账和停止，存在随机性和幻觉，确定性系统更安全可靠。
   - **失效条件**：无。

4. **循环检测为什么同时看工具+参数和状态哈希？**
   - **依据**：工具+参数抓重复动作（如模型反复调同一接口）；状态哈希抓状态停滞（如参数微变但状态不变的空转）。
   - **失效条件**：多 Agent 协作时，需扩展到 Agent 间交接层。

5. **重试有害的边界是什么？**
   - **依据**：下游无幂等保障时，重试可能导致重复副作用。
   - **失效条件**：下游无幂等保障时，重试应关闭或转人工。
